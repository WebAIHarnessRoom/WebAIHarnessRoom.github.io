设计理念与边界

设计理念

  1. 人机交互优先：Harness 首先服务于人的理解与操作，而不是追求自动化程度。
  2. 高效且透明：让人更高效地使用 Web AI，同时更清楚地知道它做了什么。
  3. 免费是入口，不是目的：不把免费能力当作价值主张，也不鼓励滥用。
  4. 不以 API 替代 Web AI：Harness 不把 Web AI 包装成 API 调用器，而是尊重其网页交互形态。
  5. Harness 自治，Room 归集：每个 Harness 独立演进，Room 只负责提供稳定入口和可发现的索引。
  6. 面向 WebAIAgent：当前以人类可读为主，结构清晰到未来可被 Agent 消费。

边界

Room 的价值是帮助人类在边界内更高效地利用 Web AI，而不是突破边界或大规模滥用免费能力。

本组织不提供绕过访问限制、批量自动化滥用或规避服务条款的方案。Harness 的设计与使用应尊重 Web AI 服务方的正常使用边界。

原则

  1. Harness 自治：每个 Harness 独立维护自己的仓库、版本和文档。
  2. 归集靠索引：Room 通过索引让分散的 Harness 可被发现，而不是把它们收编为子模块。
  3. 不设统一标准：Room 不定义“什么是合格的 Harness”，只呈现索引中已存在的 Harness 及其验证状态。
