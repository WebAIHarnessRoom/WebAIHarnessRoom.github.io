让人类更高效地驾驭 Web AI，同时更清楚地知道它做了什么。

什么是 Harness？

Harness 是包裹在 Web AI 外部的执行系统，负责提示词、工具、控制流与评测，把模型输出转化为可观察、可验证的行动。它不替代 Web AI，而是让人更高效、更透明地使用它。
