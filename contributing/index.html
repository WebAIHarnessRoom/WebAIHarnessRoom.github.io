贡献与索引维护

提交新的 Harness

  1. 确保 Harness 已以独立仓库的形式存在于 WebAIHarnessRoom 组织下。
  2. 向 room-index 提交 PR，更新索引数据文件。
  3. 在门户的 assets/data.js 中追加条目，并在 harness/<id>/index.html 下创建对应详情页。

状态语义

状态不是质量评级，而是验证状态。门户不暗示“已验证 = 推荐”。

已验证
在声明的目标 Web AI 上完成过实际验证，且最后验证日期在 90 天内。
待验证
存在于索引中，但尚未完成近期验证，或最后验证日期超过 90 天。
实验中
Harness 自身在活跃开发中，接口或行为可能变化，验证状态暂不适用。

索引字段说明

字段说明维护者
id稳定 slug，用于详情页目录名索引 PR
name与仓库 README 一致的显示名称索引 PR
tagline一句话说明，索引页与详情页共用索引 PR
target_web_ai目标 Web AI索引 PR
statusverified / pending / experimental索引 PR
last_verified最后一次实际验证的日期（YYYY-MM-DD）索引 PR
language / license / version仓库元数据索引 PR
getting_started最小可用的安装/使用命令索引 PR
boundary_note该 Harness 特有的边界说明（可选）Harness 作者

Room 不做什么

Room 不定义 Harness 的准入门槛，不认证 Harness 的质量，不把 Harness 收编为子模块。Room 只归集与呈现。详见 理念与边界。
